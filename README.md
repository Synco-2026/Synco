# Synco
Synco es un proyecto desarrollado por un equipo de 3 personas, enfocado en el debido almacenamiento de la documentacion que deben llevar las empresas a la hora de contratar y enfocado en la seguridad rapidèz y comodidad, cumpliendo con el debido abeas data, evitando tambien los problemas legales que las empresas puedan sufrir.
